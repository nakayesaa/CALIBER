IRIS competition prototype deployment

The release branch contains a snapshot of the current application and an isolated deployment layer. The original working tree has not been edited.

The prototype serves the frontend and API from one origin. Six password protected demo accounts map to server verified participants. Browser role switching is disabled. Session cookies are secure, HttpOnly, and expire after eight hours. API responses require authentication and are not cached. Mutations require the configured public origin.

Case files are bundled using authenticated AES 256 GCM encryption. The encryption key, session signing key, account hashes, and generated passwords are stored outside Git in a private local directory. Source data is not included as plaintext in the release. The application initializes data once on a persistent disk and refuses to overwrite an existing dataset with a different bundle.
